# 📇 Tarjeta de Presentación Digital – Carlos Colmenares A.

> **Ingeniería de Confianza | +40 años asegurando sistemas donde el fallo no es una opción**

Este repositorio contiene los activos y código fuente de mi **tarjeta de presentación digital**, diseñada para compartir mi perfil profesional de forma moderna, segura y eficiente —sin necesidad de papel, escaneo ni aplicaciones adicionales.

🔗 **Enlace público**: [https://cycs.netlify.app](https://cycs.netlify.app)

---

## 🎯 Objetivo

Crear una **presencia profesional en línea ligera, rápida y compatible con WhatsApp, redes sociales y mensajería**, que:

- Se comparta como un simple enlace.
- Muestre una miniatura atractiva al ser enviada (gracias a Open Graph).
- Redirija directamente a mi perfil profesional.
- Incluya respaldo visual (PNG con QR) para casos donde el enlace no muestre miniatura.

## 🛠️ Tecnologías Utilizadas

- **HTML5** + **CSS3** (ligero, sin frameworks)
- **Open Graph Protocol** para compatibilidad con WhatsApp, Facebook, LinkedIn, etc.
- **Netlify** para hosting gratuito y despliegue continuo desde GitHub
- **Imgur** (imagen de perfil pública y accesible)

## 📲 Cómo Usar Esta Tarjeta

### ✅ Opción 1: Enviar el enlace (recomendado cuando funciona la miniatura)

Envía este enlace por WhatsApp, correo o redes:

https://cycs.netlify.app

→ El receptor verá una tarjeta con tu foto, nombre y descripción.  
→ Al hacer clic, se abre tu perfil automáticamente.

### ✅ Opción 2: Enviar la imagen con QR (100% compatible)

1. Descarga `tarjetas/Carlos_Colmenares_Tarjeta_QR_Final.png`.
2. Envíala como **foto** en WhatsApp.
3. El receptor puede:
   - Ver tu información visualmente.
   - Escanear el QR con la cámara de su celular → abre tu web.
